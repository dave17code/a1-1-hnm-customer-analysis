# A1-1 · H&M 고객 구매 패턴 분석

거래·고객·상품을 미리 결합한 8컬럼 샘플로, 어떤 고객이 최근까지 자주 구매하고 많은 금액을 지출했는지 분석합니다. NumPy·Pandas·Matplotlib·Seaborn을 사용하며 보너스 과제는 포함하지 않습니다.

분석은 [노트북](notebooks/analysis_report.ipynb)의 **환경 준비 1셀 + 분석 7단계**로 실행합니다. 실제 계산은 `DataAnalyzer` 클래스에 있고, 표·그래프·해석은 노트북에 표시합니다.

## 1. 분석 입력

프로젝트 최상위의 세 파일만 읽습니다.

| 파일 | 내용 |
|---|---|
| `analysis_input.csv` | 거래 11,153행 × 8컬럼. 고객 1,000명과 상품 6,055개의 정보가 붙어 있습니다. |
| `images.npz` | 상품번호와 이미지 6,047장의 64×64×3 RGB 배열 |
| `provenance.json` | 원본 출처, 샘플 선정 조건, 결합 방법, 원본 샘플과 현재 입력의 SHA-256 기록 |

관찰 기간은 **2020-03-23~2020-09-22**, 난수 시드는 **42**입니다. 해당 기간 구매 고객에서 선택한 1,000명의 기간 내 거래를 사용합니다. 표본을 전체 H&M 고객의 대표 표본으로 단정하지 않습니다.

`analysis_input.csv`는 **H&M에서 추출한 거래·고객·상품 샘플을 결합한 분석용 입력**입니다. 원본 `t_dat`는 `order_date`, 원본 `price` 값은 `amount`로 대응했습니다. 중복된 `price`와 현재 분석에 사용하지 않는 구매 채널·상품 대분류·색상 컬럼을 제거했습니다. 남긴 값·결측치·거래 순서는 이전 입력과 같습니다. 수량이나 통화를 추정하지 않습니다.

**나이·회원 상태 결측치는 아직 남아 있고, 이미지 특성·상품명 길이·IQR·RFM은 계산하지 않은 상태입니다.** 따라서 이 작업들은 노트북을 실행할 때마다 실제로 계산합니다. 입력 파일은 실행 중 덮어쓰지 않습니다.

### 입력 컬럼

| 컬럼 | 분석에서 사용하는 곳 |

## 2. 실행 준비

**Python 3.12**를 사용합니다. 이미 현재 컴퓨터의 `.venv`에 도구를 설치했다면 재설치할 필요가 없습니다. 다른 운영체제의 `.venv`를 복사해서 사용하지 않습니다.

프로젝트 최상위 폴더에서 다음을 실행합니다.

**Windows PowerShell 또는 Git Bash**

```bash
py -3.12 -m venv .venv
./.venv/Scripts/python.exe -m pip install -r requirements.txt
```

**Mac**

```bash
python3.12 -m venv .venv
./.venv/bin/python3 -m pip install -r requirements.txt
```

Mac에서 `python3 --version`이 이미 3.12.x라면 생성 명령을 `python3 -m venv .venv`로 바꿔도 됩니다. Windows에서 `py`가 없고 `python --version`이 3.12.x라면 `python -m venv .venv`를 사용할 수 있습니다.

VS Code에서 Microsoft의 **Python**, **Jupyter** 확장을 설치하고 다음 순서로 실행합니다.

1. `notebooks/analysis_report.ipynb`를 엽니다.
2. 오른쪽 위 **Select Kernel → Python Environments → 현재 프로젝트의 `.venv`**를 선택합니다.
3. 셀 01을 실행하고 출력된 Python 경로가 현재 프로젝트의 `.venv`인지 확인합니다.
4. **Restart Kernel → Run All**로 전체 실행합니다.
5. 오류 없이 마지막 셀까지 끝나면 Windows는 `Ctrl+S`, Mac은 `Cmd+S`로 노트북을 저장합니다.

NumPy·Pandas·Matplotlib·Seaborn이 분석 라이브러리입니다. IPyKernel과 IPython은 노트북 실행·표시용이며, 이미지 처리 전용 라이브러리나 머신러닝·자동 EDA 라이브러리를 분석 코드에서 사용하지 않습니다.

## 4. 계산의 의미

- **결측치:** 고객별 한 행에서 회원 상태별 나이 중앙값으로 대치합니다. 그룹에 관측값이 없으면 전체 고객 중앙값을 사용합니다. 원래 나이 결측 고객은 3명이며, 대치값은 실제 나이의 관측값이 아닙니다. 회원 상태 누락은 `Unknown`으로 표시합니다.
- **이미지:** NumPy의 `mean(axis=(1, 2, 3))`, `std(axis=(1, 2, 3), ddof=0)`로 사진마다 픽셀 통계를 계산합니다. 사진이 없는 상품 8개의 거래는 유지하고 특성은 `NaN`, 내부 분석 표에서는 `image_missing=True`로 표시합니다. 배경·조명이 포함된 RGB 통계이므로 품질·선호를 직접 뜻하지 않습니다.
- **텍스트:** 상품명의 공백을 포함한 문자열 길이를 계산합니다.
- **IQR:** Q1−1.5×IQR, Q3+1.5×IQR를 직접 계산합니다. 원래 `amount`는 보존하고 내부 비교용 `amount_iqr`만 경계로 제한해 전후 분포를 비교합니다. 고액 거래라는 이유만으로 RFM에서 제외하지 않습니다.
- **RFM:** R은 기준일 2020-09-22에서 마지막 구매일까지의 경과일, F는 서로 다른 구매 날짜 수, M은 원래 `amount`의 합입니다. 거래 한 행을 정확한 주문·방문 횟수로 해석하지 않으며 수량을 추정하지 않습니다. 금액은 제공 단위로 유지합니다.
- **점수:** R은 작을수록, F·M은 클수록 높은 1~4점을 받습니다. 평균 순위 백분위를 사용해 동점은 같은 점수로 처리합니다.

| 그룹 | 앞선 조건을 제외하고 적용하는 점수 규칙 |
|---|---|
| VIP | R점수≥3, F점수≥3, M점수≥3 |
| Loyal | R점수≥2, F점수≥3 |
| RecentLowFreq | R점수≥3, F점수<3 |
| AtRisk | R점수=1 |
| Regular | 나머지 |

RecentLowFreq는 신규 가입을 뜻하지 않고, AtRisk는 이탈 확정을 뜻하지 않습니다. 월별 합계는 7개 달력월에 걸치며 3월은 9일, 9월은 22일만 관찰했습니다. 상관관계는 인과관계를 증명하지 않습니다.

다시 분석하려면 **Restart Kernel → Run All → 저장**을 실행합니다. 두 CSV는 해당 셀에서 같은 이름으로 덮어쓰고, 마지막 셀은 README의 `ANALYSIS_RESULTS` 표시 사이를 갱신합니다. 직접 작성한 메모는 표시 밖에 보관하세요. 중간에 오류가 나면 수정 후 처음부터 다시 실행합니다.
